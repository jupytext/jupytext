- `jupytext --paired-paths` now exits with 0 when it succeeds, rather than 1. When many files fail (e.g. `--test` or an inconsistent `--sync`), the exit code is capped at 255, since 256 failures exited with 0 on POSIX systems ([#1434](https://github.com/jupytext/jupytext/issues/1434)). Thanks to [caenrigen](https://github.com/caenrigen) for reporting the `--paired-paths` exit code.
